# 文硕阁电子书自动分类指南

## 快速开始

### 运行分类脚本

```bash
# 进入项目目录
cd wenshuoge

# 运行分类脚本
python3 scripts/classify_ebooks_auto.py
```

### 脚本做了什么？

1. **读取 CSV 元数据** - 从 `文硕阁公版书目录.csv` 加载所有书籍信息
2. **智能分类** - 根据书名、副标题和简介自动分类到 15 个类别
3. **创建组织结构** - 生成 `ebookfiles_organized/` 目录
4. **生成报告** - 生成 `分类报告.json` 显示统计信息

## 高级用法

### 修改分类规则

编辑 `scripts/classify_ebooks_auto.py` 中的 `CLASSIFICATION_RULES` 字典：

```python
CLASSIFICATION_RULES = {
    "新分类名": [
        "关键词1", "关键词2", "关键词3"
    ],
    ...
}
```

### 自定义输出目录

修改脚本中的路径：

```python
classifier = EbookClassifier(
    csv_file="文硕阁公版书目录.csv",
    source_dir="ebookfiles",
    output_dir="custom_output_dir"  # 自定义输出目录
)
```

## 故障排除

### 问题 1: 找不到 CSV 文件
```
❌ 错误: 找不到文件 文硕阁公版书目录.csv
```
**解决方案**: 确保 CSV 文��在项目根目录中

### 问题 2: 权限被拒绝
```
PermissionError: [Errno 13] Permission denied
```
**解决方案**: 使用 `chmod` 给脚本执行权限
```bash
chmod +x scripts/classify_ebooks_auto.py
```

### 问题 3: 符号链接失败
脚本会自动降级到复制文件夹模式
