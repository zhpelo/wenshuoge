# 书目增强数据

这里保存经过互联网资料核验后的书目增强记录。原始 EPUB 元数据始终保留；构建索引时，增强记录只覆盖已经人工确认的字段。

## 分批整理

每批在 `batches` 目录新增一个 JSON 文件，文件名按三位数字递增，例如 `001.json`、`002.json`。执行 `npm run index` 后，所有批次会按文件名顺序合并，后批次可修订前批次记录。

每条书目可以包含以下字段：

- `author`：核验后的作者署名
- `authorInfo`：简短作者介绍
- `period`：较精确的成书或初版年代
- `era`：用于浏览的统一时代
- `category`：统一分类
- `tags`：主题标签
- `description`：核验、润色后的书籍简介
- `sources`：支持上述信息的公开网页来源
- `reviewed`：是否已经人工核验

未进入人工批次的书目，也会在构建时根据书名、主题和简介自动生成分类、时代和基础标签。网站详情页会区分“已核验”和“自动整理”状态。

## 来源原则

优先使用国家图书馆、博物馆、大学、学术数据库、原始文本库和作者纪念机构；百科与书店页面仅作为补充。简介采用转述，不复制来源网页的长段文字。
